# Vocab Tabs — Chrome Extension Design

**Date:** 2026-06-05
**Status:** Approved

## Overview

Convert the existing Vocab Tabs web app into a Chrome Extension (Manifest V3) that replaces the browser's new tab page. Every time the user opens a new tab, they see a vocabulary word displayed in the Placard direction against a full-bleed public-domain artwork from the Art Institute of Chicago.

The existing source files are the design reference. The implementation stays as close to them as possible, removing only the Tweak Panel and the Wall and Immersive display modes.

---

## Architecture

No build step. The extension is a folder of static files loaded directly by Chrome. React and ReactDOM are downloaded locally (replacing CDN links) to satisfy Chrome's Manifest V3 content security policy, which blocks remotely-hosted scripts in extension pages.

## manifest.json

```json
{
  "manifest_version": 3,
  "name": "Vocab Tabs",
  "version": "1.0.0",
  "description": "Learn new words every time you open a new tab.",
  "chrome_url_overrides": { "newtab": "newtab.html" },
  "host_permissions": [
    "https://api.artic.edu/*",
    "https://www.artic.edu/*"
  ],
  "icons": {
    "16": "icons/icon16.png",
    "48": "icons/icon48.png",
    "128": "icons/icon128.png"
  }
}
```

- `chrome_url_overrides` is what overrides the default new tab page.
- `host_permissions` grants the extension permission to `fetch()` from the Art Institute of Chicago API and IIIF image server.
- No `permissions` array is needed — `localStorage` works in extension pages without declaration.

## Code changes

### `app.jsx`

Remove `useTweaks`, `TWEAK_DEFAULTS`, and `DIR_KEY`. Replace with hardcoded constants:

```js
const SCRIM = 0.62;
const TEXT_SCALE = 1;
```

The `App` component renders `DirectionPlacard` directly — no direction-switching logic. Accent color continues to derive from the art's color data via `ArtService.accentFrom()`. The `ControlBar` (Less, More, Next, Mark Learned, Manage) and `ManagePanel` are unchanged.

### `directions.jsx`

Remove `DirectionWall`, `DirectionImmersive`, and the `DIRECTIONS` map. Keep `DirectionPlacard`, `ArtLayer`, and `WordBlock`. Update the `window` export to only expose what remains.

### `tweaks-panel.jsx`

Deleted entirely.

### `newtab.html`

Replace CDN script tags for React and ReactDOM with local file references:

```html
<script src="react.production.min.js"></script>
<script src="react-dom.production.min.js"></script>
```

## Icons

Chrome requires icons at 16px, 48px, and 128px for display on the `chrome://extensions` page. These are not visible in the new tab UI.

A one-time Node script (`generate-icons.js`) produces the three PNGs: dark `#0c0b0a` background with a white serif "V", matching the app's visual identity. Run once, commit the output to `icons/`.

## Loading the extension

1. Open `chrome://extensions`
2. Enable Developer Mode (top-right toggle)
3. Click "Load unpacked" and select the `vocabTabs` folder
4. Open a new tab
